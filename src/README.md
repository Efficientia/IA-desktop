# EficientIA

Este é o projeto EficientIA reestruturado.

## Como rodar

1.  Certifique-se de que o arquivo `.env` está dentro da pasta `app/`.
2.  Instale as dependências:
    ```bash
    pip install -r requirements.txt
    ```
3.  Inicie o servidor FastAPI:
    ```bash
    uvicorn app.main:api --reload
    ```
